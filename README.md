# StudyWithAI - 지역 교육 문제 해결을 위한 AI 학습 플랫폼

## 🎯 프로젝트 개요
**지역 교육 격차 해결을 위한 AI 기반 스마트 학습 플랫폼**

StudyWithAI는 지역별 교육 수준 차이와 학습 접근성 문제를 해결하기 위해 개발된 AI 기반 학습 플랫폼입니다. 중고등학생부터 대학생까지 모든 학습자가 고품질의 교육 자료에 쉽게 접근하고, 개인화된 학습 경험을 통해 효과적으로 학습할 수 있도록 지원합니다.

## 🏛️ 공공 문제 해결 목표

### 📊 해결하고자 하는 지역 문제들
- **교육 격차**: 지역별 교육 수준 차이로 인한 학습 기회 불균등
- **학습 접근성**: 고품질 학습 자료에 대한 접근 제한
- **개인화 부족**: 획일화된 교육으로 인한 학습 효과 저하
- **학습 동기 부족**: 흥미를 잃기 쉬운 전통적인 학습 방식
- **교육 비용**: 사교육 의존도 증가로 인한 경제적 부담

### 🎯 공공 서비스 가치
- **교육 민주화**: 모든 학생에게 동등한 학습 기회 제공
- **지역 균형 발전**: 교육 격차 해결을 통한 지역 발전
- **사회적 가치 창출**: AI 기술을 활용한 공공 서비스 혁신
- **지속가능한 교육**: 개인화된 학습을 통한 평생학습 지원

## 🚀 핵심 기능

### 📊 학습 분석 및 피드백

## 🛠️ 기술 스택

### Frontend
- **Next.js 13**: 최신 React 프레임워크
- **TypeScript**: 타입 안전성 보장
- **Tailwind CSS**: 반응형 디자인

### Backend
- **Supabase**: 데이터베이스 및 인증
- **OpenAI API**: AI 기능 구현
- **PDF.js**: PDF 렌더링

### AI 기능
- **GPT-4**: 요약, 퀴즈 생성, 번역
- **자연어 처리**: 텍스트 분석 및 분류
- **개인화 알고리즘**: 학습자 맞춤 추천

### 파일 업로드 설정
- **최대 파일 크기**: 20MB
- **지원 파일 형식**: PDF
- **API 타임아웃**: 5분 (대용량 파일 처리용)

### 🔑 API 키 설정
- **OpenAI API 키**: [OpenAI Platform](https://platform.openai.com)에서 생성
- **API 키 형식**: `sk-`로 시작하는 **개인 API 키** (프로젝트 키 `sk-proj-` 아님)
- **환경 변수**: `.env.local` 파일에 `OPENAI_API_KEY=sk-your_key_here` 설정
- **서버 재시작**: 환경 변수 변경 후 필수
- **주의사항**: 프로젝트 키(`sk-proj-`)가 아닌 개인 API 키(`sk-`)를 사용해야 함
